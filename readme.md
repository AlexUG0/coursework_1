# Приложение для анализа банковских операций

## Описание проекта

Приложение для анализа транзакций, которые находятся в Excel-файле. <br>
Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставляет другие сервисы.

## Структура проекта
### `data` - директория с данными
#### operation.xlsx - файл данных о транзакциях
#### user_settings.json - файл пользовательских настроек с названиями валюты и акций

### `logs` - директория с журналами событий

### `src` - директория с модулями

#### `reports` - содержит функцию отчета трат по категориям
#### `services` - содержит функцию поиска по заданной строке в категориях и описании
#### `utils` - вспомогательные функции, необходимые для работы функции страницы «Главная»
#### `views` - функция для страницы «Главная» 

### `tests` - директория с файлами тестов

#### `.env.example` - описание ключей

## Установка

1. Установить [Python](https://www.python.org/downloads/) (рекомендуется версия 3.6 и выше).
2. Клонировать репозиторий на локальный компьютер:

`git clone git@github.com:ваш_пользователь/название_репозитория.git`

3. Установить необходимые зависимости:

`poetry install`

4. Перейти в директорию проекта
